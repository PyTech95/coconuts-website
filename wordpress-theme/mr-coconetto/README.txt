Mr. Coconetto – WordPress Theme
================================

INSTALL
1. WordPress admin → Appearance → Themes → Add New → Upload Theme.
2. Choose mr-coconetto-wordpress-theme.zip → Install → Activate.
   (Pretty links and 10 sample blog posts are set up automatically.)

CHANGE THE WEBSITE
- Log in to WordPress. You land on "Mr. Coconetto → Start here".
- Press "✏️ Edit the website": tap any words or picture on the website to change it,
  then press the green Save button.
- "🧩 Change sections": add / remove / move slides, services, plans, FAQ, cities …
- "🖼️ Change pictures": every picture and video in one place.
- "⏪ Undo / old versions": go back to any of the last 30 saves (or the original website).
- Blog = normal WordPress Posts. Orders and Enquiries are under the Mr. Coconetto menu.
- Email alerts for orders / enquiries: set the addresses on "Start here"
  (install "WP Mail SMTP" if emails do not arrive).

Everything is stored in WordPress itself — no other server is needed.

UPDATES
New versions are published on https://github.com/PyTech95/coconuts-website/releases
and appear under Dashboard → Updates. Your changes are kept when updating.

The theme must be installed in the site root (e.g. https://mrcoconetto.com/), not in a sub-folder.
